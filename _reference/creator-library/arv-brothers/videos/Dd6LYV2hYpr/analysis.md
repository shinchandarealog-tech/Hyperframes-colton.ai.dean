## What to steal (actionable for Hyperframes builds)
- **Text-behind-subject:** needs a person matte. Pre-generate a per-frame alpha (e.g. rembg/RVM/SAM2 to a PNG sequence or a VP9-alpha webm) and stack it as `<video>` track above the text layer, with the source plate below. Order: plate → keyword → subject matte.
- **Letter-scatter assemble:** SplitText-style per-letter spans. GSAP `from` with seeded-random x/y/z/rotation, opacity 0, stagger random 0.02, duration 0.45, ease `power3.out`. Then a glow tween (`text-shadow` blur 0→24px cyan).
- **Horizontal whip push between consecutive words:** outgoing `xPercent: 120` plus `filter: blur(12px)`, incoming from `xPercent: -120`, 0.2s, `expo.inOut`.
- **Two-voice color code:** gold for benefits, cyan for specs, lime only for price. Use the ≤5 symbolic colors rule from `MOTION_PHILOSOPHY.md`.
- **HUD stat plate** ("83" with red slash bar, "108" LED pill) over a turntable or hero shot. This is an easy reusable component.
- **Recap montage callback** at ~80% runtime (1s per feature, same cards) before the price.
- **Price as a color break:** a color used nowhere else in the video.
