# @client-ugc-reference

**Platforms:** Instagram Reels / TikTok (UGC paid-social ads, sent by the client as references)
**Niche:** UGC product ads delivered by a relatable creator at home. The first reference is a pet supplement (Pacagen).
**Why the user saves them:** The client approved these with zero revisions, so they define the bar for UGC edits.

## Signature vibe
It doesn't look like an ad. A real person in a real home vents about a specific problem, dismisses the obvious fix, then pivots ("However…") to the product. Hard cuts between a tripod talking head and phone B-roll proving every claim, small native-style captions, no motion graphics, and a close on a risk-reversal CTA.
