# @edita.visuals

**Platforms:** Instagram Reels (one sample carries the watermark @shortform.virtuososs, same template — likely a sister/repost account)
**Niche:** Short-form editing showcase. It takes podcast/interview/talking-head clips (business, AI, wellness, health, insurance) and shows the **storyboard → finished edit** side by side, promoting a Claude-driven editing workflow ("Opus 5.5", "comment CLAUDE for the full guide").
**Why the user saves them:** The user wants the polished "after" style (dense motion graphics, UI mocks, SFX on every beat), and wants to understand the storyboard-first process that produces it.

## Signature vibe
A premium "content agency" look. Talking heads are cut with literal B-roll and **HTML-style UI mock scenes** (chat inputs, progress bars, profile cards, TikTok post UIs), and captions mix a small sans lead-in with a big accent-colour keyword. Each video picks **one accent colour** (orange, purple, terracotta, lime, cobalt, golden-brown) matched to the footage. It's clean and white-canvas heavy, with soft shadows and rounded cards, and a swoosh/pop/click on nearly every visual event.
