## What to steal
- **IG/creator profile card pop-in** on each speaker's first appearance (avatar, handle, verified tick, stats row). Very cheap to build as an HTML card; scale-pop + `pop.mp3`.
- **Mixed-font keyword system**: lead-in light sans, keyword italic serif or condensed caps, chosen by emotion (calm → serif, shout → condensed caps).
- **Photo-card carousel** for any list of 3–5 nouns: tall rounded cards with a serif label, scrolling with `x` on a strip (power3.inOut, 0.5s per step).
- **Annotated diagram scene**: the hero object centred with 3–4 italic labels floating around it.
- **Text behind subject** for one climax word per video. It needs a matted/segmented subject layer. Without one, fake it with a large word behind a scaled-down face card.
- **Grade the B-roll to the face-cam palette** so the stock feels like the same world.
