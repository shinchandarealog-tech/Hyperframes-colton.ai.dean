# @finish-edits

**Platforms:** Instagram (@finish.edits)
**Niche:** Freelance video editor posting before/after showcases of business/podcast talking-head edits.
**Why the user saves them:** The user wants their own talking-head videos edited in this style (a reference reel that hit ~100k views).

## Signature vibe
Warm, cinematic, amber-graded podcast footage where every sentence is visualised: the edit cuts to illustrative inserts (AI close-ups, meme images, chalkboard explainers) and each line gets its own kinetic type treatment, with a small lead-in, a giant condensed keyword, an orange highlight box, and gold-gradient money words.
