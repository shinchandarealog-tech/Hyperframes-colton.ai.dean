## What to steal (actionable for Hyperframes builds)
- **Topic title card in the first 2–3s.** Hard-cut to a full-frame cream card and build the key phrase line by line (GSAP stagger, ~0.3s per line) in a script + bold-condensed pairing. Map to the `short-form-video` kinetic-type scene, and drop the chrome/glow from `MOTION_PHILOSOPHY.md` for this aesthetic.
- **Three-tier caption system.** (1) A small white phrase-chunk subtitle at mid-chest. (2) A two-font emphasis lockup, small bold sans word + big overlapping script word, for key words. (3) An acid-yellow italic corner line for inner thoughts. Easy to build as three caption tracks in HTML/CSS with Google Fonts (Poppins + Allura/Great Vibes + Archivo Narrow).
- **Collage B-roll insert.** A cream background with 2–3 tilted (±4–8°) `<video>` wrappers, sticker/doodle SVGs, and pieces that pop in one by one (scale 0.9→1 with back.out). Line-by-line text swaps the clip inside a slot. Use separate track indices so the swaps don't overlap.
- **Polaroid frame insert.** A white rounded polaroid with a hand-drawn red heart, and clips swapping inside per phrase. It is reusable for any "I want X, Y, Z" list beat.
- **Typewriter search bar.** A translucent pill at the top with letter-by-letter text plus a blinking cursor (GSAP `TextPlugin`, or a stepped `clip-path` / per-char spans). It's great for "actual real decisions"-style emphasis.
- **Arc text** (SVG `<textPath>`) for a dreamy aside line.
- **Mood frame for the emotional line.** Shrink the face-cam into a window over a pink bokeh-hearts background. Animate the **wrapper div**, never the `<video>` (render contract rule 9).
- **Product name write-on** in script (per-letter stagger, opacity + slight y), followed by a brand logo lockup. This is a strong UGC-ad recipe.
- **Retro device frame** (a digicam PNG over floral paper) as a one-off novelty insert near the payoff.
- **Hard cuts only, with motion inside the inserts.** This contradicts `MOTION_PHILOSOPHY.md` (no hard cuts). For this UGC aesthetic, follow the reference, or log it as a preference via `/feedback`.
- **Keep the B-roll's native subtitles** when using creator/UGC clips. It adds authenticity.
