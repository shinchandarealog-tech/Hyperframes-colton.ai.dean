# @joshrenders

**Platforms:** Instagram (reels)
**Niche:** Motion-graphics edits of podcast/interview clips. Talking-head soundbites are rebuilt as kinetic-type and collage sequences.
**Why the user saves them:** Shared as a reference for frame-level editing craft: syllable-synced single-word captions, graphic B-roll worlds between face-cam beats, and a restrained one-accent palette.

## Signature vibe
Editorial and minimal, but very fast. Hard cuts rotate between a warm podcast face-cam, an off-white graph-paper "paper world" with B&W image cards, and a black void. Words arrive as solid bars that resolve into text, and a single crimson accent flashes on stressed words. (1 video studied.)
