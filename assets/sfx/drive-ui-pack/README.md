# Drive UI pack

34 UI / motion-graphics SFX (clicks, whooshes, text, count, data, granular, rise) supplied by the creator via Google Drive, Nov 2026.
All 48 kHz 320 kbps MP3. `digital.mp3` and `text [layer1, long].mp3` are bright and hissy (30-57% energy above 6 kHz), so keep them low or skip them.
First used in video-projects/spotlight-style-transfer v3 (`_tools/audio_build_v3.py`).
