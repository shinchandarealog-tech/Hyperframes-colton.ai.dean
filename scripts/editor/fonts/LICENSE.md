# Bundled fonts

Latin subsets (woff2) from the @fontsource packages. All of them are under the SIL Open Font License 1.1, which allows commercial use, including monetized social video.

Inter, Poppins, Montserrat, Anton, Bebas Neue, Playfair Display, DM Serif Display, Permanent Marker.

When you pick a font in the editor, its files are copied into the project's `assets/fonts/` folder and loaded with `@font-face`, so the editor preview and the final render use the exact same font file.
