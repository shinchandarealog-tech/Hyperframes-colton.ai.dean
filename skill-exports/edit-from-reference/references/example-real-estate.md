# Worked example: real-estate listing reference

A compact example of the method on a real reference: a luxury home listing tour (120s, 720×1280 9:16, 24fps, voiceover). It was studied at 1 fps over the full length plus the transcript, so finer timings would need a denser pass. **Use the shape of this example for any niche.**

## Breakdown (condensed)

**Section map**
| Time | Section | What happens |
|---|---|---|
| 0–7s | Hook | Agent walks toward camera at the front door; cut to a drone shot down the winding tree-lined driveway; back to the agent |
| 7–90s | Tour | Room by room: living room (stone fireplace), kitchen, staircase, entry, primary bedroom, ensuite, shower, walk-in closet, office, gym |
| 90–95s | CTA | Agent at the front door again: "Reach out today to book your private showing." |
| 95–120s | Outro | One long, slow drone rise over the house and forest (no voice) |

**Pacing:** tour shots 2–4s each; the agent appears 3 times (open, mid-tour, close) as an anchor. The outro is a single ~25s shot, which is too long for short-form retention.

**Camera language:** smooth gimbal pushes and slides through rooms; **tilt-ups to statement light fixtures**; detail shots (sink, mirrors, closet); drone for the establishing shot and outro.

**Captions & graphics:** **none.** No on-screen price, specs, address or agent name. The voiceover carries every fact ("custom-built 2025… 1.2 private acres… 3,300 sq ft… heated three-car garage").

**Script → visual mapping:** each feature mentioned is shown roughly when it's said (kitchen line → kitchen). The facts (acres, sq ft, garage) are spoken over unrelated room shots, so they're missed opportunities.

**Sound:** a soft music bed under the voiceover; the voice ends ~94s, then music only.

**Grade:** bright, neutral-warm, clean whites; natural greens outside.

**Signature moves:** the agent as a walking host at the door (bookends); fixture tilt-ups; drone open and close.

## Style spec (what a client asking for "this style" wants)

- Host-led tour: agent bookends (open + CTA), gimbal room-by-room, drone open and close, tilt-ups to fixtures.
- Calm pace, 2–4s per shot; bright clean grade; soft music under a warm voiceover.

## Mapping to a new client's footage + upgrades from the principles

The spec stays (it's what the client liked). Upgrades are offered as **options in the plan, not imposed**:

| Gap in the reference | Option to offer |
|---|---|
| No on-screen facts | **Spec tags** on the spoken word: "1.2 ACRES", "3,300 SQ FT", "3-CAR HEATED GARAGE" (pattern P18), in the client's brand color |
| No hook text | First-second hero line over the drone shot: "**1.2 private acres** / just outside the city" (P01/P21) |
| Facts spoken over unrelated rooms | Re-order shots so each fact lands on its matching visual (garage line → garage shot) |
| 25s silent drone outro | Trim to ~4–6s with the price/CTA card (P03) and agent contact, held ≥1s |
| Long tour for social | Make a 30–45s cut: hook, 6–8 best rooms at 1.5–2.5s each, 2–3 spec tags, CTA |

## Edit-plan beat example

```
Beat 1 · 0.0–2.4s · "Welcome to this stunning custom-built executive home…"
  A · Drone driveway + hero line (suggested) — P21 + P01 · like ref @0:02 drone
      What animates: drone push down the driveway; "custom-built / executive home" small,
      hero "1.2 ACRES" lands on "acres"
      Why: hook needs a visual + the strongest fact in second 1
  B · Agent walk-to-camera, no text — like ref @0:00 (pure reference style)
  C · Front-door detail → whip to drone — P26 punch-in
```
