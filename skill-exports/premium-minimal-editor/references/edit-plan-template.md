# Edit-plan template

Deliver this BEFORE building anything. The human picks; Claude builds.

## Header

```
<Speaker> · <topic> — edit plan
Clip: <file> (silences cut, <old>s → <new>s) · 9:16 1080×1920 30fps · Style: premium minimal · <N> beats
Heads-up: <burned-in text / tricky framing / anything that forces a choice>
Caption fixes vs. transcript: <Whisper mistakes → correct words>
```

## One block per beat

```
Beat <n> · <start>–<end>s · "<exact script line>"
  A · <name> (suggested) — <archetype + ID>
      What animates: <precise: what, where, when it lands (on which word)>
      Why: <scene-choice logic: announce = face / describe = show / number = graph …>
  B · <name> — <archetype + ID>
      What animates: …
      Why: …
  C · <name> — <archetype + ID>
      What animates: …
      Why: …
  Notes: ______
```

Rules for the options:
- Always offer at least one option that **needs no stock assets** (face punch-in, text card, reusing the client's own footage).
- Never suggest the same archetype for two consecutive beats.
- Cite the animation library ID and, where useful, which reference it comes from.

## How to collect the user's choices

- **Desktop or browser user:** an interactive page (radio buttons per beat, a notes box, a "copy plan" button) works well.
- **Phone or chat-app user:** ask in chat as multiple-choice questions, 4 beats per batch, with an "Other" option for their own idea. Don't send an HTML file they can't interact with.
- Finish with any asset questions ("Do you have your own close-ups, or should I source free stock?").
