# Edit-plan template

Deliver this BEFORE building anything. The human picks; Claude builds.

## Header

```
<Speaker / brand> · <topic> — edit plan
Niche preset: <preset or client brand> · accent <hex> · fonts <sans> + <emotion>
Clip: <file> (silences cut, <old>s → <new>s) · 9:16 1080×1920 30fps · <N> beats
Heads-up: <burned-in text / framing problems / anything that forces a choice>
Caption fixes vs. transcript: <transcription mistakes → correct words>
```

## One block per beat (≈2–5s, one spoken thought)

```
Beat <n> · <start>–<end>s · "<exact script line>"
  A · <name> (suggested) — <pattern ID>
      What animates: <what, where, and which word it lands on>
      Why: <scene-choice logic: announce = face / describe = show / number = graph …>
  B · <name> — <pattern ID>
  C · <name> — <pattern ID>
  Notes: ______
```

Rules for the options:
- At least one option per beat that **needs no stock** (face punch-in, a text card, the client's own footage).
- Never suggest the same pattern for two consecutive beats.
- Prefer options that match the niche preset's cutaway language.

## Collecting choices

- **Desktop / browser:** an interactive page (pick per beat, a notes box, a "copy plan" button).
- **Phone / chat app:** multiple-choice questions in chat, ~4 beats per batch, with an "Other" option. Don't send an HTML file the user can't interact with.
- Finish with asset questions ("Do you have your own close-ups, or should I source free stock?").
